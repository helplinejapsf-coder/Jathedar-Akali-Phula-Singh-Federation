AI Assistant Security Policy

  • AI ਨੂੰ Admin Panel ਜਾਂ admin APIs ਦੀ ਪਹੁੰਚ ਨਾ ਹੋਵੇ।
  • AI ਸਿਰਫ਼ public website content ਅਤੇ admin-approved public FAQs ਪੜ੍ਹੇ।
  • Member, donor, payment ਅਤੇ problem records AI ਨੂੰ ਨਾ ਭੇਜੋ।
  • Passwords, API keys, database secrets ਅਤੇ private exports ਕਦੇ expose ਨਾ ਕਰੋ।
  • ਇਹ ਨਿਯਮ backend authorization ਨਾਲ ਲਾਗੂ ਕਰੋ; ਸਿਰਫ਼ prompt ਨਾਲ ਨਹੀਂ।

Security Settings

  • Server-side authentication ਅਤੇ MFA ਲਾਜ਼ਮੀ ਕਰੋ।
  • Role-based access control (RBAC) ਲਾਗੂ ਕਰੋ।
  • Database row-level security ਅਤੇ least-privilege policies ਵਰਤੋ।
  • Secrets ਨੂੰ server environment ਵਿੱਚ ਰੱਖੋ, HTML/JavaScript ਵਿੱਚ ਨਹੀਂ।
  • Audit logs ਅਤੇ session expiry ਲਾਗੂ ਕਰੋ।
